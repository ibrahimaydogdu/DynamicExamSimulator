**9. (Klasik Soru - 20 Puan)**  
Kütlesi $100\text{ kg}$ olan küçük bir yarış arabası, sürtünmesiz bir pistte A noktasından durgun halden harekete başlıyor. Pist profili $y = 0.05x^2$ parabolik denklemi ile tanımlanmıştır. Araç $x = 10\text{ m}$ konumundaki B noktasına ulaştığında ($g = 9.81\text{ m/s}^2$):  
a) Aracın B noktasındaki hızını ($v_B$),  
b) Pistin araca B noktasında uyguladığı normal tepki kuvvetini ($N$),  
c) Aracın B noktasındaki teğetsel ivmesini ($a_t$) hesaplayınız.  

### Formüller

| | |
| :--- | :--- |
| $v = \frac{ds}{dt}, \quad v_x = \dot{x}, \quad v_y = \dot{y}$ | $a = \frac{dv}{dt}, \quad a_x = \ddot{x}, \quad a_y = \ddot{y}$ |
| $a\,dx = v\,dv$ | $v = v_0 + a_c t$ |

| $v_r = \dot{r}, \quad v_\theta = r\dot{\theta}$ | $a_r = \ddot{r} - r\dot{\theta}^2, \quad a_\theta = r\ddot{\theta} + 2\dot{r}\dot{\theta}$ |
